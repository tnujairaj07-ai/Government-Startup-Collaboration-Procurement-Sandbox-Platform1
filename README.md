# Mahatech Procure – Government-Startup Procurement & Innovation Sandbox Platform

An enterprise-grade GovTech platform built with React, TypeScript, Vite, and Tailwind CSS. It facilitates collaboration between Government Departments and DeepTech Startups through outcome-based problem statements, multi-dimensional AI shortlisting, pre-pilot expert evaluations, live IoT telemetry monitoring, bilateral digital contract workflows, and GeM integration.

## 🏛️ Key Capabilities & Modules

- **Government Executive Command Dashboard**: Official profile, pending actions table, department KPIs, and audit trail.
- **Outcome-Based Challenge Studio**: 6-step challenge creator with dynamic readiness score, 10-dimension rubric weighting, and MeitY cybersecurity constraints.
- **Verified Startup Directory**: Multi-attribute filtering across domains, sectors, DPIIT verification, and 7-tab startup dossiers.
- **AI Evaluator & Shortlisting Engine**: 10-dimension explainability scorecard, weight tuning, and automated shortlist handoff.
- **Pre-Pilot Expert Evaluation**: Independent panel review, structured evaluator notes, and pilot clearance gate.
- **Work Area / Telemetry Monitor**: Real-time IoT sensor telemetry graphs, pressure transients, anomaly detection, and milestone tracking.
- **Problem Statement (PS)–Driven Contract Approval**: Bilateral contract sign-offs, Government Resolution (GR) orders, and escrow disbursements.
- **Founder Command Workspace (Startup Portal)**: Verified Evidence Passport, challenge explorer, proposal tracking, and pilot delivery workspace.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Run
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
